The design system of the dashboard: tokens, type, spacing and every reusable component with its states. This page uses the stylesheet of the application unchanged, so it cannot drift from it.

1. Colour tokens

Each token has a light and a dark value; the page follows the system setting or the choice in the footer of the dashboard. Blue marks data, red marks alerts only, and a state never relies on colour alone: it carries an icon or a label.

3. Spacing, radius, targets

One scale of steps; a control is never lower than 2.75rem (44 px), the minimum touch target.

0.25rem · inside chips
0.5rem · between controls
0.75rem · grid gap
1rem · cell padding, phone gutter
1.5rem · desktop gutter
2.125rem · between sections
2.75rem · minimum height of a control

Radius: 0.25rem chips · 0.375rem controls · 0.625rem panels · full for pills. Borders and the focus ring stay in px: 1 px and 2 px.
