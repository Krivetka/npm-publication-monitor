# Заявления

**Использование ИИ.** При подготовке этого документа и прототипа автор использовал Claude Code (Anthropic, модель Claude Fable 5.1): для редактирования английского текста по заметкам автора и для проверки оформления на соответствие требованиям программы. Все измерения, проектные решения, анализ источников и аналогов и выводы принадлежат автору и проверены им.

**Тип проекта.** Индивидуальный проект.

**Данные организаций.** Проект использует только общедоступные данные реестра npm и публичных API; внутренние данные организаций не использовались, поэтому согласие организации не требовалось.
